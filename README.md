# Sistema de Gestão de Agendamentos Médicos

Projeto desenvolvido para a disciplina de Programação de Sistemas (PDS) do curso de Sistemas de Informação na UFU. O sistema permite o gerenciamento de consultas médicas, conectando pacientes e médicos através de uma interface intuitiva e persistência de dados.

## 🛠 Tecnologias e Ferramentas

*   **Linguagem:** Java (JavaFX para interfaces gráficas)
*   **Banco de Dados:** SQLite
*   **Gerenciador de Dependências:** Maven
*   **Metodologia:** Scrum (Gestão de Sprints e Backlog)

## 🎯 Objetivo do Sistema

Proporcionar um fluxo eficiente para:
*   Cadastro e autenticação de usuários (Pacientes e Médicos).
*   Agendamento de consultas com lógica de disponibilidade e horários.
*   Gestão de perfis e horários de atendimento profissional.
*   Navegação dinâmica baseada em diferentes perfis de acesso.
