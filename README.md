# Sistema de Gestão de Agendamentos Médicos

Projeto desenvolvido para a disciplina de Programação de Sistemas (PDS) do curso de Sistemas de Informação na UFU. O sistema permite o gerenciamento de consultas médicas, conectando pacientes e médicos através de uma interface intuitiva e persistência de dados.

## 🛠 Tecnologias e Ferramentas

*   **Linguagem:** Java (JavaFX para interfaces gráficas)
*   **Banco de Dados:** SQLite
*   **Gerenciador de Dependências:** Maven
*   **Metodologia:** Scrum (Gestão de Sprints e Backlog)

## 🎯 Objetivo do Sistema

Proporcionar um fluxo eficiente para:
*   Cadastro e autenticação de usuários (Pacientes e Médicos).
*   Agendamento de consultas com lógica de disponibilidade e horários.
*   Gestão de perfis e horários de atendimento profissional.
*   Navegação dinâmica baseada em diferentes perfis de acesso.

## 🚀 Como rodar o projeto localmente

### 📋 Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina:
*   **Java JDK** (versão 11 ou superior).
*   Uma IDE para desenvolvimento Java (recomenda-se IntelliJ IDEA, Eclipse ou NetBeans).

### 🛠️ Passo a passo para execução

**1. Clone o repositório**  
Abra o seu terminal e digite o comando abaixo para baixar o código:

```bash
git clone https://github.com/VitorVieira28/AgendamentoClinicaPDS.git
```

**2. Abra o projeto na sua IDE**  
Inicie a IDE de sua preferência, vá em `File > Open` (ou Import) e selecione a pasta do projeto que você acabou de clonar.

**3. Configure as dependências (Bibliotecas)**
*   **JavaFX:** Certifique-se de que a SDK do JavaFX está configurada na sua IDE para que as telas gráficas funcionem.
*   **SQLite:** Verifique se o driver JDBC do SQLite (ex: `sqlite-jdbc.jar`) está adicionado nas dependências (Build Path) do projeto.

**4. Rode a aplicação**  
No explorador de arquivos da IDE, navegue até a classe principal do sistema, clique com o botão direito e selecione **Run**. A tela inicial do sistema deverá abrir automaticamente!
